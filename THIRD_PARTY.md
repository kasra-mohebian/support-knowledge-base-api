# Third-party components

No dependency source code, model weights or external datasets are vendored here. Installing the requirements downloads separate packages whose licenses remain applicable.

The primary runtime components are FastAPI (MIT), Uvicorn (BSD-3-Clause), Starlette (BSD-3-Clause) and Pydantic (MIT). Python and its SQLite module use Python's license; SQLite itself is public domain. Refer to the installed distributions' license files for authoritative terms for all direct and transitive packages.

- [FastAPI license](https://github.com/fastapi/fastapi/blob/master/LICENSE)
- [Uvicorn license](https://github.com/Kludex/uvicorn/blob/main/LICENSE.md)
- [Starlette license](https://github.com/Kludex/starlette/blob/main/LICENSE.md)
- [Pydantic license](https://github.com/pydantic/pydantic/blob/main/LICENSE)
- [Python license](https://docs.python.org/3/license.html)
- [SQLite copyright statement](https://www.sqlite.org/copyright.html)
